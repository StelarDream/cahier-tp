Op-Amp Circuits

The two golden rules. Inverting, non-inverting, follower, integrator, differentiator, active filters.

§1 — The Op-Amp as a Component

The operational amplifier (AOp, ALI) is an active component: it requires an external power supply \(\pm U_{cc}\) to function. It has two signal inputs — non-inverting \((E^+)\) and inverting \((E^-)\) — and one output \(S\).

Ideal model

For all calculations in this course, the op-amp is assumed ideal:

PropertyIdeal valuePhysical meaning
Input impedance \(Z(E^\pm)\) \(\infty\) No current flows into either input: \(i(E^+) = i(E^-) = 0\).
Output impedance \(Z_s\) \(0\) Output can drive any load without voltage drop. \(U_s\) is independent of \(i_s\).
Open-loop gain \(A_d\) \(\infty\) \(U_s = A_d \cdot \varepsilon\). With \(A_d \to \infty\) and \(U_s\) finite: \(\varepsilon \to 0\) in linear regime.

Two operating modes

Once powered, the op-amp operates in one of two modes depending on whether negative feedback is present:

ModeConditionOutputRule 1 applies?
Saturated Open loop — no feedback from \(S\) to \(E^-\) \(U_s = +U_{cc}\) if \(\varepsilon > 0\); \(U_s = -U_{cc}\) if \(\varepsilon < 0\) No — \(\varepsilon \neq 0\)
Linear Closed loop — negative feedback from \(S\) to \(E^-\) \(-U_{cc} < U_s < +U_{cc}\) Yes — \(\varepsilon = 0\)
Never connect the output directly to the masse — this is a short circuit and will destroy the op-amp. Always verify that negative feedback is present before applying \(\varepsilon = 0\). Feedback must go from \(S\) to \(E^-\), not \(E^+\) (which would be positive feedback → instability).

§2 — The Two Golden Rules

In linear regime with ideal op-amp, two rules govern all calculations. Memorise these — everything else is derived from them.

$$\boxed{\varepsilon = V(E^+) - V(E^-) = 0} \qquad \Leftrightarrow \qquad V(E^+) = V(E^-)$$
Rule 1 — virtual short circuit between inputs (linear regime only)
$$\boxed{i(E^+) = i(E^-) = 0}$$
Rule 2 — no current into either input (always valid for ideal op-amp)

Why Rule 1 holds

The output law is \(U_s = A_d \cdot \varepsilon\). With negative feedback, \(U_s\) is bounded: \(|U_s| < U_{cc}\). Since \(A_d \to \infty\):

$$\varepsilon = \frac{U_s}{A_d} \xrightarrow{A_d \to \infty} 0$$
Rule 1 derivation — consequence of infinite gain + finite output

The inputs are not physically connected — the op-amp actively drives its output to whatever value makes \(\varepsilon = 0\). This is the meaning of negative feedback: the output adjusts itself until the two inputs are equalised.

Systematic derivation method

Every linear op-amp circuit is solved by the same procedure:

  1. Find \(V(E^+)\) — usually direct from the input via a voltage divider or direct connection.
  2. Set \(V(E^-) = V(E^+)\) (Rule 1).
  3. Apply KCL at the \(E^-\) node using Rule 2 (\(i(E^-) = 0\)) — all branch currents sum to zero.
  4. Solve for \(U_s\).

§3 — Standard Circuits

Comparator (open loop)

\(U_e\) applied to \(E^+\), \(E^-\) grounded. No feedback — Rule 1 does not apply.

$$U_s = \begin{cases} +U_{cc} & \text{if } U_e > 0 \\ -U_{cc} & \text{if } U_e < 0 \end{cases}$$
comparator — output is always saturated

Voltage follower (montage suiveur)

\(U_e\) to \(E^+\), output fed directly to \(E^-\) (\(R_2 = 0\), \(R_1 = \infty\)).

$$V(E^+) = U_e \quad \xrightarrow{\varepsilon=0} \quad V(E^-) = U_e \quad \xrightarrow{V(E^-)=U_s} \quad \boxed{U_s = U_e, \quad G_v = 1}$$
follower derivation

The follower has infinite input impedance and zero output impedance. It passes the signal unchanged while completely decoupling the source from the load — eliminating the loading effect of L4 §3.

Non-inverting amplifier

\(U_e\) to \(E^+\). Feedback via voltage divider \(R_1\) (to ground), \(R_2\) (from output).

$$V(E^+) = U_e \xrightarrow{\varepsilon=0} V(E^-) = U_e \xrightarrow{\text{divider}} \frac{R_1}{R_1+R_2}U_s = U_e$$
non-inverting — step by step
$$\boxed{U_s = \left(1 + \frac{R_2}{R_1}\right) U_e} \qquad G_v = 1 + \frac{R_2}{R_1} \geq 1$$
non-inverting amplifier — gain always ≥ 1, same sign as input

Inverting amplifier

\(U_e\) via \(R_1\) to \(E^-\). \(R_2\) from output to \(E^-\). \(E^+\) grounded.

$$V(E^+) = 0 \xrightarrow{\varepsilon=0} V(E^-) = 0 \quad \text{(virtual ground)}$$
inverting — E⁻ is at virtual ground
$$\text{KCL at } E^-: \quad \frac{U_e}{R_1} + \frac{U_s}{R_2} = 0 \qquad \Rightarrow \qquad \boxed{U_s = -\frac{R_2}{R_1}\,U_e}$$
inverting amplifier — gain can be any value, sign inverted

Summing amplifier

Multiple inputs \(U_{e1}, U_{e2}, U_{e3}\) via \(R_1, R_2, R_3\) to \(E^-\). Feedback \(R_4\). \(E^+\) grounded.

\(V(E^-) = 0\) (virtual ground). KCL at \(E^-\) with Rule 2:

$$\frac{U_{e1}}{R_1} + \frac{U_{e2}}{R_2} + \frac{U_{e3}}{R_3} + \frac{U_s}{R_4} = 0$$
summing amplifier — KCL at virtual ground node
$$\boxed{U_s = -R_4\!\left(\frac{U_{e1}}{R_1} + \frac{U_{e2}}{R_2} + \frac{U_{e3}}{R_3}\right)} \xrightarrow{R_1=R_2=R_3=R} U_s = -\frac{R_4}{R}(U_{e1}+U_{e2}+U_{e3})$$
summing amplifier — weighted sum of inputs

Differentiator

C in the input branch (from \(U_e\) to \(E^-\)), R in the feedback branch.

$$i_C = C\frac{d(u_e - 0)}{dt} = C\frac{du_e}{dt} \qquad i_R = \frac{0 - u_s}{R} \qquad \xrightarrow{i_C + i_R = 0}$$
differentiator — KCL at virtual ground
$$\boxed{u_s(t) = -RC\,\frac{du_e(t)}{dt}} \qquad \underline{H}(j\omega) = -jRC\omega$$
differentiator — time domain and phasor domain

Integrator

R in the input branch, C in the feedback branch.

$$i_R = \frac{u_e}{R_1} \qquad i_C = C\frac{du_s}{dt} \qquad \xrightarrow{i_R + i_C = 0}$$
integrator — KCL at virtual ground
$$\boxed{u_s(t) = -\frac{1}{R_1 C}\int_0^t u_e(\tau)\,d\tau} \qquad \underline{H}(j\omega) = \frac{-1}{jR_1C\omega}$$
integrator — time domain and phasor domain
The integrator amplifies low frequencies strongly (\(|\underline{H}| \sim 1/\omega\)) and any residual DC offset \(U_d\) at the input will be integrated indefinitely, driving the output to saturation. Fix: place a large resistor \(R_2\) in parallel with C. This turns the ideal integrator into a pseudo-integrator with \(\underline{H} = -R_2/R_1 \cdot 1/(1+jR_2C\omega)\) — a low-pass filter with gain \(R_2/R_1\) at low frequencies.

§4 — Active Filters

Passive filters (L4) have two limitations: the transfer function changes when a load is connected, and the gain is always \(\leq 1\). Active filters solve both by incorporating an op-amp.

Follower + passive filter

The simplest approach: passive filter → follower. The follower's infinite input impedance means \(i_s = 0\) from the filter's perspective — the loading effect vanishes and \(f_c\) is unchanged regardless of what load follows.

Active high-pass filter (inverting)

Replace \(R_1\) in the inverting amplifier with a series RC (C then R). Input branch impedance: \(\underline{Z}_1 = R_1 + 1/jC\omega\). Feedback: \(\underline{Z}_2 = R_2\). Apply the inverting formula with complex impedances:

$$\underline{H}(\omega) = -\frac{\underline{Z}_2}{\underline{Z}_1} = -\frac{R_2}{R_1 + 1/jC\omega} = -\frac{jR_2C\omega}{1 + jR_1C\omega}$$
active high-pass filter — inverting configuration
$$G_{v,\text{max}} = \frac{R_2}{R_1} \qquad f_c = \frac{1}{2\pi R_1 C}$$
active high-pass — gain and cutoff frequency independent of load

The gain in the passband is \(R_2/R_1\) — which can be \(> 1\). This is impossible for a passive filter. The cutoff frequency depends only on \(R_1\) and \(C\), not on the load.

Active low-pass filter (inverting)

Replace \(R_2\) with a parallel RC (R in parallel with C). Feedback impedance: \(\underline{Z}_2 = R_2/(1 + jR_2C\omega)\):

$$\underline{H}(\omega) = -\frac{R_2}{R_1}\cdot\frac{1}{1+jR_2C\omega} \qquad G_{v,\text{max}} = \frac{R_2}{R_1} \qquad f_c = \frac{1}{2\pi R_2 C}$$
active low-pass filter — inverting configuration

§5 — Saturation and Real Op-Amp Limits

Finding the saturation threshold

In linear regime: \(|U_s| < U_{cc}\). The maximum input before saturation is:

$$|U_{e,\text{max}}| = \frac{U_{cc}}{|G_v|}$$
saturation threshold — maximum linear input amplitude

Example: non-inverting with \(G_v = 10\), \(U_{cc} = 15\,\text{V}\): \(U_{e,\text{max}} = 1.5\,\text{V}\). Any input above 1.5 V peak will clip the output.
