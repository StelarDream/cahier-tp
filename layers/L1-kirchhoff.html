§1 — The Lumped Circuit Approximation

Maxwell's equations govern electromagnetic fields continuously through all of space. Circuit theory is not that — it is a drastically simplified model that replaces fields with scalar voltages and currents. The simplification is valid under one condition: the lumped circuit approximation.

The condition is that the physical size of the circuit \(L_\text{circuit}\) must be much smaller than the wavelength \(\lambda\) of the signals it carries:

$$L_\text{circuit} \ll \lambda = \frac{c}{f}$$
lumped approximation condition

At \(f = 1\,\text{kHz}\): \(\lambda \approx 300\,\text{km}\). A breadboard is invisible to the wave — the approximation is perfect. At \(f = 1\,\text{GHz}\): \(\lambda \approx 30\,\text{cm}\). Your circuit is now comparable to the wavelength and the lumped model breaks down — you need transmission line theory or full field simulation.

Under this approximation, three things become true:

  • The potential \(V\) is well-defined at every node (no significant field variation within a component).
  • The current \(I\) entering one terminal of a branch equals the current leaving the other (no charge accumulation inside).
  • Energy is stored only in capacitors and inductors, dissipated only in resistors — not radiated.
KVL failing in the presence of a varying magnetic flux is not a failure of the lumped approximation — it is a separate effect. When \(\partial\vec{B}/\partial t \neq 0\) threads a loop, \(\text{rot}\,\vec{E} \neq \vec{0}\) and \(\oint \vec{E}\cdot d\vec{l} \neq 0\). KVL picks up an EMF term: \(\sum_k U_k = -d\Phi/dt\). This is induction (CM5), valid at any scale. See L0 §4.

§2 — Nodes, Branches, Meshes

A circuit is a graph. The vocabulary:

TermFrenchDefinition
Node Nœud A point (or region) of equal potential. Three or more branches meet here. KCL applies.
Branch Branche A two-terminal element (or series of elements) connecting two nodes. Carries one current \(I\), has one voltage \(U\) across it.
Mesh / Loop Maille A closed path through branches returning to the starting node. KVL applies.
Ground / Masse Masse The reference node. \(V = 0\) by convention. All other potentials are measured relative to it.

This is exactly the node/pin model: a node is an equipotential (one scalar \(V\)), a branch is a directed edge (one scalar \(I\), one scalar \(U = V_A - V_B\)). The open problem — how does \(U\) and \(I\) distribute across branches at a node — is answered by KCL and KVL together, which form a linear system. The component laws of L2 close the system.

§3 — Kirchhoff's Current Law (KCL)

Root in L0

From the continuity equation (L0 §1): \(\partial\rho/\partial t + \text{div}\,\vec{j} = 0\). In the lumped static regime, charge does not accumulate at a node: \(\partial\rho/\partial t = 0\). Therefore \(\text{div}\,\vec{j} = 0\) at every node, which by Green-Ostrogradski integrates to:

$$\oiint_S \vec{j}\cdot d\vec{S} = 0 \quad \Rightarrow \quad \sum_k I_k = 0$$
KCL — from field form to circuit form

Statement

At any node \(N\), the algebraic sum of all currents is zero:

$$\sum_k I_k = 0$$
KCL — loi des nœuds

With the convention that currents entering the node are positive and currents leaving are negative, this is simply: total charge in = total charge out. No charge accumulates.

The number of independent KCL equations for a circuit with \(n\) nodes is \(n - 1\). The equation for the last node is always a linear combination of the others — it carries no new information.

§4 — Kirchhoff's Voltage Law (KVL)

Root in L0

From Maxwell-Faraday in the static limit (L0 §4): \(\text{rot}\,\vec{E} = \vec{0}\), which by Stokes' theorem gives:

$$\oint_\mathcal{C} \vec{E}\cdot d\vec{l} = 0$$
conservative circulation — integral form of static Faraday

Since \(U_{AB} = \int_A^B \vec{E}\cdot d\vec{l}\), walking around any closed loop and summing the voltages gives zero:

$$\sum_k U_k = 0$$
KVL — loi des mailles

Statement

Around any closed loop, the algebraic sum of all voltages is zero. Choose a direction of traversal. For each branch: if you traverse it in the direction of the voltage arrow (from \(-\) to \(+\)), add \(+U_k\); if you traverse against it, add \(-U_k\).

The number of independent KVL equations for a circuit with \(b\) branches and \(n\) nodes is \(b - n + 1\) — the number of independent meshes (cyclomatic number of the graph).

Generator and receiver conventions

Two sign conventions define how \(U\) and \(I\) relate for a branch:

ConventionRelationMeaning
Générateur \(U > 0,\; I > 0\) same direction Voltage and current arrows point the same way. The element delivers power: \(P = UI > 0\).
Récepteur \(U > 0,\; I > 0\) opposite directions Voltage and current arrows oppose. The element absorbs power: \(P = UI > 0\).

§5 — The Voltage Divider

The single most-used circuit identity in this course. Two impedances \(Z_1\) and \(Z_2\) in series, driven by \(u_e\), with output taken across \(Z_2\):

$$\boxed{u_s = \frac{Z_2}{Z_1 + Z_2}\, u_e}$$
voltage divider — general form with complex impedances

Derivation from KVL + Ohm

KVL around the single mesh: \(u_e = u_1 + u_2\). Since \(Z_1\) and \(Z_2\) carry the same current \(i\) (series), \(u_1 = Z_1 i\) and \(u_2 = Z_2 i\). So \(u_e = (Z_1 + Z_2)\,i\), giving \(i = u_e/(Z_1+Z_2)\). Then:

$$u_s = Z_2\, i = \frac{Z_2}{Z_1 + Z_2}\, u_e$$
voltage divider — derived
Critical condition: this formula holds only when no current is drawn from the output node — i.e. the current through \(Z_1\) and \(Z_2\) is the same. If a load \(Z_L\) is connected across \(Z_2\), the effective impedance becomes \(Z_2 \| Z_L = Z_2 Z_L/(Z_2+Z_L)\) and the formula changes. This is the loading effect — studied experimentally in TP3-5. The op-amp follower in L5 exists precisely to eliminate it.

Why this formula runs the whole course

Every passive filter transfer function is a voltage divider with complex impedances. In L3, \(Z_C = 1/(jC\omega)\) and \(Z_L = jL\omega\) replace real \(R\)s. The RC low-pass filter is literally:

$$H(\omega) = \frac{U_s}{U_e} = \frac{Z_C}{Z_R + Z_C} = \frac{1/jC\omega}{R + 1/jC\omega} = \frac{1}{1 + jRC\omega}$$
RC low-pass — voltage divider with \(Z_C\) (preview of L3–L4)

§6 — Series and Parallel Combinations

Series — from KVL

Elements in series carry the same current. KVL gives \(u_e = \sum_k u_k = \sum_k R_k\, i\). So the equivalent resistance seen from the terminals is:

$$R_\text{eq} = \sum_k R_k = R_1 + R_2 + \cdots$$
series combination — KVL derivation

Parallel — from KCL

Elements in parallel share the same voltage. KCL gives \(i_e = \sum_k i_k = \sum_k U/R_k = U \sum_k 1/R_k\). So:

$$\frac{1}{R_\text{eq}} = \sum_k \frac{1}{R_k} \qquad \Rightarrow \qquad R_\text{eq} = \frac{R_1 R_2}{R_1 + R_2} \;\text{(two resistors)}$$
parallel combination — KCL derivation

Both identities generalise immediately to complex impedances: replace every \(R_k\) with \(Z_k(\omega)\). Series and parallel combinations of capacitors and inductors follow the same algebra — with \(Z_C\) and \(Z_L\) substituted in.
