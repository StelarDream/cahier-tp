Active Filter (Op-Amp)

Bode diagram of the active CR high-pass filter. Two configurations: unity gain (\(R_1=R_2\)) and amplifying (\(R_2 > R_1\)). Verify \(f_c\) is load-independent and \(G_v > 1\) is achievable.

Theory Recap

The active CR high-pass filter uses an inverting op-amp with \(C\) in the input branch (impedance \(\underline{Z}_1 = R_1 + 1/jC\omega\)) and \(R_2\) as feedback:

$$\underline{H}(\omega) = -\frac{R_2}{R_1 + 1/jC\omega} = -\frac{jR_2C\omega}{1 + jR_1C\omega}$$
active high-pass — inverting configuration
$$G_{v,\text{max}} = \frac{R_2}{R_1} \qquad f_c = \frac{1}{2\pi R_1 C}$$
passband gain and cutoff frequency — both independent of load

Key differences from the passive CR filter: \(G_v\) can exceed 1 when \(R_2 > R_1\), and \(f_c\) does not shift when a load is connected (the op-amp output impedance is zero). The inversion (−) means output is 180° out of phase with input in the passband.
