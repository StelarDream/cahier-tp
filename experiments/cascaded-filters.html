Theory Recap

Both circuits use the same components: \(R = 1\,\text{k}\Omega\), \(C = 1\,\mu\text{F}\), giving \(\omega_0 = 1/RC\) and \(f_0 = 1/(2\pi RC) \approx 159\,\text{Hz}\).

CR-CR — order-2 high-pass

Two CR stages in cascade, derived via transfer matrices (TP5). The total transfer function is not simply the square of one stage because the second stage loads the first:

$$\underline{H}(\omega) = \frac{1}{1 - (\omega RC)^2 + 3j\omega RC}$$
CR-CR order-2 high-pass — transfer matrix method

The cutoff frequency solves \(|\underline{H}(\omega_c)| = 1/\sqrt{2}\), giving \(\omega_c = \sqrt{0.14}\,\omega_0 \approx 0.374\,\omega_0\):

$$f_c = \frac{\sqrt{0.14}}{2\pi RC} \approx \frac{0.374}{2\pi RC}$$
CR-CR cutoff frequency — below the single-stage \(f_0\)

Stopband slope: \(-40\,\text{dB/decade}\) — double that of a single CR stage.

CR-RC — band-pass

A CR high-pass stage followed by an RC low-pass stage. The CR passes high frequencies, the RC attenuates them — the combined response has a peak in the middle:

$$\underline{H}(\omega) = \frac{j\omega RC}{(1 + j\omega RC)^2}$$
CR-RC band-pass — same \(R\), \(C\) for both stages

Maximum gain at \(f_0 = 1/(2\pi RC) \approx 159\,\text{Hz}\), where \(|\underline{H}| = 1/2\) (i.e. \(-6\,\text{dB}\)). The two cutoff frequencies are both at \(f_0\) (they coincide because the components are identical), giving bandwidth \(\Delta f = f_0\).
